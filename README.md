# 🎓 Sistema Escolar Salesforce

Sistema de gestão escolar desenvolvido na plataforma Salesforce, utilizando LWC (Lightning Web Components) e Apex.

## 📋 Sobre o Projeto

Projeto desenvolvido para praticar o fluxo completo de desenvolvimento Salesforce em ambiente profissional, simulando o workflow de empresas como o Itaú com uso de Git, GitHub, VS Code e Salesforce CLI.

## 🚀 Tecnologias Utilizadas

- **Salesforce LWC** (Lightning Web Components)
- **Apex** (backend Salesforce)
- **Salesforce CLI** (SF CLI)
- **Git & GitHub** (versionamento)
- **VS Code** (desenvolvimento)

## 📦 Funcionalidades

- ✅ Listagem de Alunos com filtro por Status
- ✅ Listagem de Professores
- ✅ Listagem de Turmas com relacionamento ao Professor
- ✅ Botão de novo registro direto no componente
- ✅ Contador de registros exibidos em tempo real

## 🗂️ Objetos Customizados

| Objeto | Descrição |
|--------|-----------|
| `Aluno__c` | Dados dos alunos matriculados |
| `Professor__c` | Dados dos professores |
| `Turma__c` | Turmas com relacionamento ao Professor |
